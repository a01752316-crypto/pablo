# 🏭 PABLO — Digitalización y monitoreo de líneas de producción

Proyecto colaborativo de innovación industrial desarrollado en la concentración de **Sistemas y Tecnologías 4.0 del Tecnológico de Monterrey, campus Puebla**, en colaboración con **GUREAK CINIA**.

El proyecto busca desarrollar e implementar una solución tecnológica que permita visualizar y consultar el estado de las líneas de producción dedicadas al armado de arneses eléctricos, integrando dispositivos electrónicos, comunicación de datos, almacenamiento y visualización de información.

## 🎯 Objetivo

Desarrollar una plataforma de monitoreo que permita consultar el estado de las líneas de producción en tiempo real, centralizando la información capturada y presentándola mediante tableros visuales claros y accesibles.

## ⚙️ Tecnologías utilizadas

El proyecto contempla herramientas de integración, almacenamiento y visualización de datos para conectar el entorno físico con los sistemas digitales.

| Tecnología | Función dentro del proyecto |
|---|---|
| **Node-RED** | Desarrollo de flujos para integrar dispositivos, procesar señales y gestionar el intercambio de información. |
| **PostgreSQL** | Almacenamiento y organización de los registros del proceso productivo. |
| **Grafana** | Creación de dashboards para visualizar información y monitorear el estado de la producción. |
| **Raspberry Pi** | Plataforma de computación para apoyar la integración de dispositivos y la comunicación de datos. |

## 🔄 Flujo general de información

La solución se basa en la integración de los componentes físicos y digitales para facilitar el seguimiento del proceso productivo.

1. **Captura de información:** obtención de datos relacionados con los estados de las piezas y las líneas de producción.
2. **Integración y procesamiento:** gestión de los datos mediante flujos de comunicación y procesamiento.
3. **Almacenamiento:** organización de la información para su consulta y seguimiento.
4. **Visualización:** representación de los datos mediante tableros que facilitan el monitoreo de la producción.

*Nota: este flujo es conceptual. La arquitectura y las conexiones específicas dependen de la implementación del sistema.*

## 🚀 Instalación y ejecución

No se requiere instalar dependencias para visualizar la página principal.

### Opción 1. Descargar el repositorio

1. Descarga el repositorio desde GitHub mediante la opción **Code → Download ZIP**.
2. Extrae los archivos en una carpeta local.
3. Abre el archivo `index.html` en un navegador web.

### Opción 2. Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/a01752316-crypto/pablo.git
cd pablo
```

Después, abre `index.html` en tu navegador.

> **Importante:** la página informativa puede abrirse directamente en el navegador. La ejecución de la plataforma de monitoreo industrial completa requiere que los componentes y servicios correspondientes estén configurados.

## 🏭 Aplicación en la Industria 4.0

Este proyecto integra conocimientos de automatización, electrónica, programación, bases de datos y análisis visual para desarrollar una solución orientada a las necesidades de un entorno industrial.
