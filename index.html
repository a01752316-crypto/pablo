PROYECTO COLABORATIVO

¿En qué consiste el proyecto?

Como parte de la concentración de Sistemas y Tecnologías 4.0 en el Tecnológico de Monterrey, campus Puebla, los ocho integrantes estamos desarrollando e implementando un sistema para visualizar en tiempo real el estado de las líneas de producción dedicadas al armado de arneses eléctricos de GUREAK CINIA.

La solución integra dispositivos electrónicos, comunicación de datos, almacenamiento y visualización para facilitar el seguimiento de los estados de las piezas y ofrecer información útil sobre el proceso productivo.

🎯

Nuestro objetivo

Desarrollar una plataforma de monitoreo que permita consultar el estado de las líneas de producción en tiempo real, centralizando la información capturada y presentándola mediante tableros visuales claros y accesibles.

⚙️ Tecnologías utilizadas

Herramientas que conectan el entorno físico con la información digital.

🔀

Node-RED

Desarrollo de flujos mediante programación visual para procesar señales, integrar dispositivos y gestionar el intercambio de información.

Integración y procesamiento
🗄️

PostgreSQL

Base de datos relacional para almacenar y organizar los registros de los estados de las piezas y la información del proceso.

Almacenamiento de datos
📊

Grafana

Creación de dashboards para representar visualmente los datos y facilitar el monitoreo del estado de la producción.

Visualización y monitoreo
🍓

Raspberry Pi

Plataforma de computación utilizada para apoyar la integración de dispositivos y la comunicación de información dentro del sistema.

Integración electrónica
📡

ESP32

Microcontrolador empleado para capturar señales del proceso y transmitir datos hacia el sistema de monitoreo.

Captura y comunicación de señales

🔄 ¿Cómo funciona el sistema?

Del estado físico de la producción a la información visual.

PASO 01
📥

Captura

Los dispositivos electrónicos reciben las señales del proceso productivo.

PASO 02
🔀

Procesamiento

Node-RED integra y gestiona los datos recibidos de los dispositivos.

PASO 03
🗄️

Almacenamiento

PostgreSQL organiza los registros de los estados de las piezas.

PASO 04
📈

Visualización

Grafana presenta los datos en dashboards para consultar el estado de producción.

Esquema conceptual del flujo de información. La integración específica depende de la arquitectura implementada en el proyecto.

Ingeniería aplicada a la industria 4.0

Este proyecto nos permite aplicar conocimientos de automatización, electrónica, programación, bases de datos y análisis visual para desarrollar una solución tecnológica orientada a las necesidades reales de un entorno industrial.
